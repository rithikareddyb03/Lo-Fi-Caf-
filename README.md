# Lo-Fi-Caf-
Soundboard &amp; Pomodoro Timer
Create a cozy, animated desktop environment meant to help people study. Think of a virtual café window with rain effects, a customizable ambient sound mixer, and a sleek Pomodoro timer.


1.Pomodoro Timer
Start, pause, and resume a countdown timer
Reset the timer back to its full duration at any point
Skip the current session instantly
Switch between three modes — Focus (25 min), Short Break (5 min), and Long Break (15 min)
Watch a glowing SVG ring progress arc shrink in real time as the session counts down
Receive a completion modal with a soft audio chime when the session ends
Let the app auto-suggest the next mode (focus → short break → long break after 4 sessions)
Track completed focus sessions using four fillable session dots


2.Ambient Sound Mixer
Toggle any of 6 ambient sounds on or off individually — Rain, Café Chatter, Train Tracks, Fireplace, Wind, Keyboard
Mix multiple sounds simultaneously to create a custom soundscape
Adjust the volume of each active sound independently using a per-tile slider
Control the overall output level using a master volume slider
Hear all sounds synthesized live in the browser — no audio files or downloads required


3.Scene & Weather Switcher
Switch between 5 animated background scenes — Rainy Night, Golden Hour, Foggy Morning, Clear Night, Snowy
Watch the sky gradient transition smoothly between scenes
See animated rain falling during Rainy Night
See animated snowflakes drifting during Snowy
Watch floating ambient particles drift upward in every scene
View a layered city skyline silhouette that reacts to the scene lighting
See desk props in the foreground — a steaming coffee cup, a book, and a swaying plant


4.Task Manager
Type and add a new task by pressing Enter or clicking the + button
Check off completed tasks with a checkbox (strikethrough applied automatically)
Delete any task using the × button that appears on hover
See a live count of remaining uncompleted tasks update automatically
Scroll through tasks if the list grows long


5.Motivational Quotes
Read a motivational or study-focused quote displayed at the bottom right
Click the refresh button to instantly load a new random quote with a fade transition
See quotes automatically rotate every 3 minutes without any interaction


6.Live Clock & Date
See the current time displayed in the header, updating every 10 seconds
See today's date (day, month, date format) displayed alongside the clock
